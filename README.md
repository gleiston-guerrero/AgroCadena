# AgroCadena
Código fuente del Proyecto AgroCadena, caso integrador del libro «Guía para el desarrollo de sistemas de información basados en Internet de las Cosas» (UTEQ). Sistema IoT para monitorizar la cadena de frío de banano y cacao: sensores LoRaWAN, pasarela de borde, MQTT, Spring Boot, PostgreSQL/TimescaleDB, Vue 3 y Flutter.
